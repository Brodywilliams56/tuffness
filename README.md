# Responsive Landing Page

A simple, responsive landing page built with **plain HTML, CSS, and JavaScript**. It showcases a hero section with navigation, three feature cards, and a footer. The design adapts gracefully to mobile, tablet, and desktop screens.

---

## ✨ Features
- **Hero Section** with a headline, sub‑headline, and call‑to‑action button.
- **Responsive Navigation** that collapses into a hamburger menu on small screens.
- **Three Feature Cards** highlighting product benefits.
- **Footer** with copyright information.
- Mobile‑first layout using Flexbox and CSS custom properties.
- Small JavaScript snippet for the mobile navigation toggle.

---

## 🛠️ Tech Stack
- **HTML5** – Semantic markup.
- **CSS3** – Custom properties, Flexbox, media queries.
- **JavaScript (ES6)** – Simple DOM manipulation for the mobile menu.

## 🚀 Getting Started
1. **Clone the repository** (or download the files):
   ```bash
   git clone https://github.com/Brodywilliams56/tuffness.git
   cd tuffness
   ```
2. **Open the page**:
   - Locate `index.html` in the project root.
   - Double‑click the file or open it in a browser via:
     ```bash
     open index.html   # macOS
     # or
     start index.html  # Windows
     ```
   No server, build step, or package manager is required.

## 🎨 Customization
- **Colors & branding** – Edit the CSS variables in `:root` (e.g., `--primary`, `--bg-hero`).
- **Content** – Replace the placeholder text in `index.html` with your own copy.
- **Additional sections** – Duplicate the `<article class="card">` block to add more feature cards, or add new sections following the existing markup pattern.
